| P1 | Commits dominate the scheduler's cost. Measured in 3.6 (400 executions waiting on one inbox, about 1,200 heap objects, 401 commits): 1.25 s in all, about 3 ms a commit, growing with the square of the executions. About 83% of it is `commit` (scheduler/wake.ts): writing each snapshot through the zod codec and canonical JSON, then reading it back so the next segment restores what a restart would see.
