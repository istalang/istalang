# Lowering and Definition IR

## Units

- lower a checked program or its `@Suite` tests into a `Definition` → `lower`, `lowerTests` (`src/compiler/lowering/lower.ts`)
- intern modules, constants, function instances or closing `any` entries → `DefinitionTables` (`src/compiler/lowering/tables/tables.ts`); number any function-table entry → `DefinitionTables.index`, over its kind's identity (`src/compiler/lowering/tables/entries.ts`)
- the type a parameter's argument arrives in, a reference for a `&` parameter → `parameterTypeOf` (`src/compiler/lowering/tables/parameter-types.ts`)
- assemble a code entry from the code a `CodeWriter` wrote → `codeEntry` (`src/compiler/lowering/functions/code-entry.ts`), the one builder, which function lowering and synthesized code both call
- add a kind of function-table entry → its variant in `LoweredEntry` (`tables/entries.ts`) and its row, identity and entry, in `entryKinds` (`src/compiler/lowering/entry-kinds.ts`); nothing else dispatches on the kind
- intern concrete `Definition` type entries → `TypeTable` (`src/compiler/lowering/tables/type-table.ts`)
- lower a function instance or nested function body → `instanceLowering`, `nestedLowering` (`src/compiler/lowering/functions/index.ts`); the entry of a function with no body of its own, built from its parameters once its prologue computed them (a struct's or variant's fields, a primitive operation's extern, a host extern's wrapper, a native extern's defaults) → `builtLowering`, `FunctionLowering.lowerBuilt`, and its entries `structEntry`, `constructorEntry`, `primitiveEntry`, `hostExternEntry`, `externDefaultsEntry` (`src/compiler/lowering/functions/built-entries.ts`); what an instance's own entry is made of (a primitive operation's extern included, which a call writes inline: `emitPrimitive`), decided once for lowering and the tables → `ownEntryOf` (`src/compiler/lowering/tables/own-entries.ts`)
- build the `LoweredFunction` for an instance or nested entry → `loweredInstance`, `loweredNested`; an instance's defaults as its prologue reads them → `defaultsReading` (`src/compiler/lowering/functions/frames.ts`)
- the arrays what `hold`s keep, per scope and type → `HoldLists` (`src/compiler/lowering/flow/hold-lists.ts`); how a flow's root gives its value and the epilogue of one written inline → `FlowEnd`, `givenInline` (`flow/flow-end.ts`); the registers allocated since a point → `CodeWriter.registersSince`
- name what writing an entry takes beyond its code, the checker and the tables → `Lowering` (`src/compiler/lowering/context.ts`); never a local interface of the two
- lay out the `Frame` for an instance, a built or a nested entry → `instanceFrame`, `builtFrame`, `nestedFrame` (`src/compiler/lowering/functions/frames.ts`); a context constant's accessor → `accessorLowering` (`functions/index.ts`), `accessorFrame` (`functions/frames.ts`); the body a function's lowering lowers → `writtenBodyOf` (`functions/bodies.ts`)
- a register with the type of what it holds, a kind of type where it is known → `TypedValue<Of>` (`src/compiler/lowering/context.ts`); never another `{ register, type }` shape, nor one extended by its own fields where `TypedValue` extends
- declare a frame's parameters, running its prologue: each parameter a call leaves out computed from its default, read through the child context `EntryContext.inDefaults` gives, then the `body` marker → `declareFrame` (`src/compiler/lowering/functions/frame-variables.ts`); never compute a default in a caller
- close a `ResolvedCall` against an instantiation's substitution/witnesses, as far as it goes (a requirement on an `any` value or on another function's type parameters stays open) → `closedInside`, `closingIn`, `closedFunctionCall`; a function with its type arguments and witnesses → `FunctionInstance`, `substitutionOf` (`src/compiler/checker/surface/witness-closing.ts`), given the checker as a `Closer` (its type rules, and the witnesses a requirement on a computed type takes once known); what a closed call targets in lowering, an entry or a dispatch → `closeCall`, `closeCallWithin` (`src/compiler/lowering/calls/closed-calls.ts`)
- close a `FunctionCall` or a trait witness call → `closeFunctionCall`, `closeWitness` (`src/compiler/lowering/calls/closed-calls.ts`)
- read what a closed call gives, or how it or a dispatch maps its function's types (the constraint's trait arguments and `Self` included) → `resultOfCall`, `substitutionOfCall`, `dispatchSubstitution` (`src/compiler/lowering/calls/closed-calls.ts`)
- build a root `FunctionInstance` → `rootInstance` (`src/compiler/lowering/tables/instances.ts`); the entry a call leaving parameters out calls, its function's own or an extern's defaults entry → `DefinitionTables.leavingOutIndex`; whether a function value of a shorter type leaves any out → `leavesOut` (`src/compiler/lowering/calls/closed-calls.ts`)
- allocate registers, place labels, and emit jumps, branches or instructions → `CodeWriter` (`src/compiler/lowering/functions/code-writer.ts`), via `context.code`
- write code with no syntax behind it (codecs, a host's extern constant's read, `any` dispatch, async fits) → `SynthesizedCode` (`src/compiler/lowering/synthesized/index.ts`); pass its parameters on, those it takes by `&` by `&` (into a part too) → `SynthesizedCode.passedOn`; pass by `&` a value it has no place for → `SynthesizedCode.inCell`
- build a struct from registers by its fields' names, or a tuple, with a body or without → `construct`, `tupleOf` (`src/compiler/lowering/values/struct-values.ts`, on `CodeContext`); the built-in `==`/`!=`, `not`, or whether a `compare`'s result is in a relation → `equal`, `negated`, `ordered` (`src/compiler/lowering/values/operators.ts`); a struct's value rebuilt as another struct type of some or all of its fields, by name (a nominal value as its shape, §3.1; a pattern's rest, §3.11) → `rebuiltAs` (`src/compiler/lowering/values/struct-values.ts`)
- the value of a type holding one (§3.5, §4): a member parameter over literal types named as a value, or a field loop's key in its pass over fields not known yet → the flow computation `typeValue` (`src/compiler/checker/surface/flow-ir.ts`), written once instantiation makes its type a literal → `literalTypeForm` (`src/compiler/checker/surface/constant-form.ts`), which compile time reads too (`rules/computation/`)
- write a body's code: its flow's operations and exits mapped to instructions, one register per flow value, blocks laid out with each field loop's passes run once per field → `writeFlow` (`src/compiler/lowering/flow/writer.ts`), `operationWriters` (`flow/operations.ts`), `exitWriters` (`flow/exits.ts`), `layoutOf` (`flow/layout.ts`); a body's flow → `CheckedBody.flowOf`, `CheckedBody.nestedFlowOf` (`src/compiler/checker/surface/checked-body.ts`); never walk a body's syntax to lower it
- read a part of a value as a flow's `read` does (a step, behind a handle, inside an optional, a keyed field) → `partRead` (`src/compiler/lowering/flow/parts.ts`); a field a trait requires, on a value whose type lowering knows, an instance's or an `any` member's: its stored field, else its getter's call (§3.10) → `readRequiredField` (`src/compiler/lowering/values/required-fields.ts`); write a flow's `Place`, or pass it by `&` (copied in and out where it is no variable's) → `writePlace`, `passedArguments` (`src/compiler/lowering/flow/places.ts`)
- decide which reads of a flow (a variable at a name, a part, what a handle holds) hold their value, as something may change it before their last use → `heldReads`, `readFactsOf` (`src/compiler/lowering/flow/held-reads.ts`), which `FlowWriter.write` runs; a held read is copied where it is defined (`FlowWriter.holds`)
- emit a direct or closed `call` instruction → `emitCall`, `emitFunctionCall`, `referenceTo` (`src/compiler/lowering/calls/emit-call.ts`)
- the mode of an entry lowering writes, from its function's kind, or the kind an entry built as a function of a type waits in → `codeModeOf`, `builtKindOf` (`src/compiler/lowering/functions/modes.ts`)
- write code inside a field loop's pass (§4): the body read as that pass checked it, so its calls close and its types concretize through the pass's `CheckedBody.substitution` (its key bound), nested functions keyed per pass → `FunctionContext.inFieldPasses`, a child context sharing the entry's code, never one swapped in under a callback (`src/compiler/lowering/context.ts`), `loweredNested` and `passedBody` (`src/compiler/lowering/functions/frames.ts`), `BodyOwner.passes` (`src/compiler/lowering/tables/instances.ts`); an instantiated body has one pass per field, in field order, its key bound in its substitution: the one home of unrolling (`instantiationBy`, `src/compiler/checker/wiring/body/facts/instantiation.ts`)
- read or write the field a key of several names names, or a part past it, switching on its tag → `readKeyed`, `writeKeyed`, `eachKeyedField`, and convert a value written there into the concrete field, also where an instantiation left the key one name (an `AssignedPart` whose `WrittenFit` is `'intoKeyedField'`) → `fittedInto` (`src/compiler/lowering/values/keyed-fields.ts`); run code per member of a union value → `onEachMember`, or into one register → `eachMember` (`src/compiler/lowering/values/members/index.ts`)
- read a tuple's item, a struct's field or a known variant's field, borrowed → `CodeWriter.tupleItem`, `CodeWriter.structField`, `CodeWriter.variantField` (`src/compiler/lowering/functions/code-writer.ts`); compare two registers with the built-in `equal` → `CodeWriter.equal`, or `equal` (`values/operators.ts`) for `!=` too
- a variable's register, any flow of the entry writing it → `VariableRegisters.registerOf`, `variableRegister`; the type a variable's register holds, concrete in the instance → `variableType`, `concreteType` (`src/compiler/lowering/flow/variables.ts`); a register of a type, owning or borrowed → `CodeWriter.allocate`, `CodeWriter.borrow`; a register's type and lifetime are read off it by every backend (`lifetimeOf`, `src/definition/tables/types.ts`), never noted beside it
- read how a field access reaches its field → `CheckedBody.fieldReadOf` (`src/compiler/checker/surface/checked-body.ts`)
- build an enum variant by its declared name → `buildVariant`, by its position → `variantAt`, or what a variant's constructor builds of its parameters → `buildConstructed` (`src/compiler/lowering/values/variant-values.ts`); in synthesized code, `SynthesizedCode.variant`
- branch on one or several of an enum's variants (to a `Branch`, `functions/code-writer.ts`), or read variant field 0 → `branchOnVariants`, `payloadOf` (`src/compiler/lowering/values/variant-values.ts`); carry on with a variant's one field where a value holds it, else run what leaves → `payloadOr`
- build `none`, branch on whether a `T?` holds a value, or read it where it does → `noneOf`, `branchOnPresent`, `insideOptional` (`src/compiler/lowering/values/optionals.ts`)
- put a value into a union, take one out as a member or a narrower union (or, where an instantiation collapsed it, as literals merged into its base, or out of the `any` type that took its members whole), write a union of literals as its base, write something per member's value → `intoUnion`, `outOfUnion`, `asBase`, `oneValueIn`, `eachMember` (`src/compiler/lowering/values/members/index.ts`)
- where a value of one type sits in a value of another as an instantiation made both (its own variant, its literal's base's, inside the `any` type it converted into, or inside a union's `any` member that took it whole; a recursive type laid out as what it unfolds to, `laidOutAs`), and reading or building it → `Holding`, `holdingOf`, `readHeld`, `heldAt`, `heldStep`, `heldIn`, `heldInAny`, `memberValue`, `laidOutAs` (`src/compiler/lowering/values/members/holdings.ts`); testing which member a value holds, a literal merged into its base compared, a downcast's test included → `branchOnMembers`, `branchOnHeld`, `jumpIfHeld` (`values/members/tests.ts`); a downcast reads through `readHeld`; a member's value is read only through `heldAt`, never a hand-written `field: 0`; an enum's, union's or `any`'s variant is built only by `variantAt` (`values/variant-values.ts`); never patch a layout an instantiation changed; a union's variants in order and the one holding a member → `TypeTable.unionMembers`, `unionVariant`; an `any` type's variant holding a type and what it holds there, its base → `TypeTable.anyVariant` (`HeldVariant`, which `heldAt` takes), so no caller applies `baseOf` to read it; never build a union's variant by hand

## One-way rules

- Emit every `call` through `emitCall` / `emitFunctionCall`, and every value conversion through `FunctionContext.fitted`.
- The order a body runs in and what it releases where are decided once, by its flow (`checker/rules/flow/build/`); lowering maps each operation and exit to instructions (`lowering/flow/`) and decides nothing of either. A construct's meaning changes in the flow builder, never in lowering.
- A function converted to another function type is a closure of one `wrapping` conversion entry (`wrappingEntry`, `DefinitionTables.index`); never an entry kind of its own for one form of it, a plain function made async included. A future it gives is followed by one of its own (`convertedFuture`, prelude `_converted`, runtime/run/following.ts), never awaited by an entry of its own, so the call stays the function's.
- Lower every checked body through `instanceLowering`, `nestedLowering` or, for a context constant's initializer, `accessorLowering` (`functions/index.ts`), and syntaxless code through `SynthesizedCode`.
- Lower std code a program needs only once it reaches a function, as the job server once it reaches `runtime.delegate`, from `lower` (`src/compiler/lowering/lower.ts`), naming it in the Definition as `main` is, never from code every program reaches.
- Never recognize a `Definition` type by name string at runtime; use `TypeDefinition.role` (`hasRole`, `isResourceType` in `src/definition/tables/types.ts`).
- The lowering writes every point a register lets go its flow says, and the runtime never infers a scope (`src/definition/instructions/lifetimes.ts`): `letGo` at a block's end on every exit, a statement's or header's end and `drop`, an `append` into the hold scope's array for `hold`, and `return` letting go of every register.

## Recipes

### Add a Definition instruction kind

1. Define the schema with `defineInstruction` in `src/definition/instructions/` (`data.ts`, `calls.ts`, `control.ts`, `places.ts`, `suspension.ts`, or `lifetimes.ts`).
2. Add its handler to `operandsOf` (`instruction.ts`), the verifier's `effects` (`src/definition/validation/ownership.ts`) and validation's `partSteps` (`src/definition/validation/parts.ts`): the part it steps into, checked against its type, or `noPart`.
3. Give the verifier a broken mutant of it where it holds or lets go (`brokenMutants`, `src/definition/validation/ownership.test-kit.ts`).
4. Add its emitter to `src/codegen/instructions.ts` (docs/arch/codegen.md), and snapshot rules if it waits or holds registers (`src/runtime/snapshot/`).
